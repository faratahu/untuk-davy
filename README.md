# Untuk Davy Wahyu Saputra

Halaman surat romantis dengan amplop interaktif, ilustrasi bunga, dan lagu Indecision oleh Rex Orange County feat. Daniel Caesar, dibuat untuk Davy Wahyu Saputra.

## Membuka halaman

Buka `index.html` melalui peramban. Halaman menggunakan HTML dan CSS statis tanpa proses build.

Klik **Buka suratku** atau segel amplop untuk membuka surat. Tombol **Tutup amplop** mengembalikan tampilan awal dan menghentikan pemutar musik.

## Musik

Musik diputar melalui embed video resmi YouTube, bukan salinan berkas audio:
[Rex Orange County feat. Daniel Caesar - Indecision (Official Video)](https://www.youtube.com/watch?v=uh0SpzMsZAs).

Pemutar hanya dimuat setelah amplop dibuka. Situs meminta autoplay, tetapi izin peramban, ketersediaan YouTube, dan pengaturan pemilik video dapat mengharuskan pengunjung menekan Play atau membuka YouTube langsung. Tidak ada klaim bahwa musik sudah berbunyi hanya karena iframe berhasil dibuat.

## Mengubah pesan

Ubah paragraf di bagian `message` dalam `index.html`. Warna, tata letak, dan animasi bunga terdapat di `style.css`.
