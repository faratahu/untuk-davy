# Untuk Davy Wahyu Saputra

Halaman surat romantis dengan ilustrasi bunga, dibuat untuk Davy Wahyu Saputra.

## Membuka halaman

Buka `index.html` melalui peramban. Halaman menggunakan HTML dan CSS statis tanpa proses build.

## Mengubah pesan

Ubah paragraf di bagian `message` dalam `index.html`. Warna, tata letak, dan animasi bunga terdapat di `style.css`.

## Privasi

Repository dan halaman ini dipublikasikan dengan izin pemilik. Seluruh isi pesan dan nama yang ditampilkan dapat dibaca publik.
